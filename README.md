# سبيس

تطبيق أندرويد مستقل. في النظام اسمه **سبيس** ويظهر ضمن **الألعاب**، لا ضمن التطبيقات التي تفتح الروابط.

## التثبيت

1. افتح [صفحة الإصدارات](https://github.com/aalbahrii999/sabees/releases).
2. حمّل `sabees.apk`.
3. على الجوال اسمح بالتثبيت من المتصفح أو من تطبيق الملفات.
4. افتح **سبيس**.

أول بناء يظهر بعد دقائق من رفع الكود، داخل تبويب Actions ثم Releases.

## ماذا يفعل

- فتح الصفحات والبحث
- تحديث الصفحة، والرجوع، والتقدم
- سجل، وعلامات محفوظة، وتبويبات
- وضع سطح المكتب، وتحميل الملفات

البيانات تبقى على الجهاز. لا حساب ولا مزامنة.

يُثبَّت يدوياً، ولا يسجّل نفسه لفتح روابط `http` من خارج التطبيق.
